EASY CYPRUS — INSTALLATION GUIDE
=================================

This zip is self-contained. No SSH, terminal, or Composer/NPM access is needed —
only cPanel File Manager and phpMyAdmin (or the MySQL Databases tool).

STEP 1 — Create a database
---------------------------
1. In cPanel, open "MySQL Databases".
2. Create a new database (e.g. yourusername_easycyprus).
3. Create a new database user with a password, and add that user to the
   database with ALL PRIVILEGES.
4. Write down: database host (usually "localhost"), database name,
   database username, and database password. You'll need these in Step 3.

STEP 2 — Upload and extract
-----------------------------
1. In cPanel File Manager, go to public_html (or the subdomain's document
   root if you're using a subdomain — e.g. public_html/easycyprus).
2. Upload this zip file there.
3. Right-click the zip and choose "Extract". Make sure the files end up
   directly inside that folder (you should see index.php, .htaccess,
   setup.php, and a laravel/ folder side by side — not nested one level
   deeper in a subfolder).
4. Make sure the "laravel" folder (and everything inside it) is readable,
   and that "laravel/storage" and "laravel/bootstrap/cache" are writable
   by the web server. On most cPanel accounts this is already correct
   after extraction; if the setup wizard reports a permissions error,
   set those two folders to 755 (or 775) via File Manager's Permissions
   dialog.

STEP 3 — Run the setup wizard
--------------------------------
1. Visit https://yourdomain.com/setup.php (or your subdomain's URL) in a
   browser.
2. Fill in the database host, name, username, and password from Step 1,
   and your site's full URL (e.g. https://yourdomain.com).
3. Click "Install". This creates the database tables, seeds starter data
   (cities, categories, demo businesses), and creates an admin account.
4. On success you'll see the admin login:
     Email:    admin@easycyprus.com
     Password: Admin@2026!
   Log in at https://yourdomain.com/admin/login and change this password
   from the admin Users screen right away.

That's it — visit your site's homepage to see it live.

TROUBLESHOOTING
----------------
- "Already installed": setup.php locks itself after first success. To
  re-run it (this wipes and reseeds the database), delete
  laravel/storage/app/installed.lock via File Manager, then visit
  /setup.php again.
- Database connection errors: double-check the host/name/user/password
  from cPanel's MySQL Databases page — the username is usually prefixed
  with your cPanel account name (e.g. yourusername_dbuser).
- If the wizard reports it could not run migrations automatically, it
  will show a URL you can open once in your browser to finish the
  install manually (this happens on hosts that disable shell_exec/exec).
- Blank page after install: check that mod_rewrite is enabled for your
  hosting account (nearly all cPanel hosts have this on by default).
