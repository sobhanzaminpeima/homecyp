# AI chat

The HomeCyp root page is a multilingual full-screen real-estate assistant. It combines deterministic property search and financial tools with an LLM conversational layer.

## Supported experiences

1. Property purchase and resale search.
2. Investment discovery and ROI analysis.
3. Daily rental, long-term rental, and Airbnb discovery.
4. Area recommendations across North Cyprus.
5. Mortgage, comparison, residency, and purchase timeline tools.
6. Saved conversation history and cross-turn preferences.
7. Image, PDF, TXT, CSV, and JSON attachments.
8. Voice input and browser speech output.
9. Viewing requests, lead capture, email, WhatsApp, and CRM handoff.

The UI supports English, Turkish, Persian, Arabic, Russian, and German. `RagPipelineService` detects each message language, updates the conversation locale, and asks the model to reply in that language.

## Request pipeline

1. `ChatWindow::send()` validates and stores the user turn immediately.
2. Attachments are stored and safe text is extracted.
3. The browser renders the message and a progressive thinking state.
4. `ChatWindow::processReply()` calls `RagPipelineService`.
5. The pipeline detects intent and facts such as budget, range, area, bedrooms, and purpose.
6. Hybrid search retrieves knowledge context.
7. `PropertySearchService` queries active inventory for property intents.
8. An LLM generates structured answer text, quick replies, follow-up questions, and memory updates.
9. Returned property IDs are intersected with server-side results, preventing invented listings.
10. Financial and legal-sensitive widgets are generated by deterministic PHP services.
11. The response, cards, widget, and memory are persisted and rendered by Livewire.

When a property intent has no match, the pipeline returns a localized deterministic no-result response instead of allowing fabricated options.

## Providers

`LlmManager` supports NVIDIA NIM and OpenAI for chat/embeddings, plus Anthropic for chat. The active provider comes from admin settings, then `config/llm.php`. Failures open a one-minute circuit breaker and try configured fallbacks. Embeddings are cached for seven days.

```dotenv
LLM_CHAT_PROVIDER=nvidia_nim
LLM_EMBEDDING_PROVIDER=nvidia_nim
LLM_CHAT_FALLBACKS=openai,anthropic
LLM_EMBEDDING_FALLBACKS=openai
```

## Knowledge base

Filament manages knowledge sources. `KnowledgeIngestService` chunks source content, creates embeddings, and stores searchable chunks. `HybridSearchService` combines vector similarity with text relevance.

Use verified area guides, buying procedures, residency guidance, fee schedules, FAQs, and project documents. Do not ingest unverified legal or financial claims.

## Attachments and OCR

`AttachmentTextExtractor` reads supported text formats and attempts PDF extraction. Scanned PDFs and images can use an optional Document AI endpoint:

```dotenv
DOCUMENT_AI_URL=https://document-service.example/api/extract
DOCUMENT_AI_TOKEN=
```

## Lead and workflow integrations

- Lead capture is a soft prompt and never blocks chat.
- Signed-in leads can recover saved conversations.
- Viewing intent can create a request and confirmation email.
- WhatsApp offers human-advisor handoff.
- `CrmWebhookConnector` can deliver events to an external CRM.

```dotenv
WHATSAPP_NUMBER=905338456497
CRM_WEBHOOK_URL=
CRM_WEBHOOK_TOKEN=
```

## Guardrails

- Only active database inventory can become an organic property card.
- Investment searches exclude nightly rentals.
- Purchase budgets do not silently match rental prices.
- No-match responses are deterministic and localized.
- Financial calculations use server-side tools.
- Legal and financial output includes a verification reminder.
- Chat sends and sign-in attempts are rate limited.
- Lead conversations are isolated by session and ownership.
- Uploaded and remote content is treated as data, not instructions.

## Admin surfaces

- **Chat Settings:** welcome copy, starter cards, voice toggle.
- **LLM Settings:** providers and extra system instructions.
- **Knowledge Sources:** content, processing, embeddings.
- **AI Analytics:** usage, feedback, inventory quality.
- **Recommendation Rules:** recommendation behavior.
- **Sponsored Campaigns:** paid results and click tracking.
